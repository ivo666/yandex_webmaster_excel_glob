# Yandex Webmaster Excel Glob (ETL Pipeline)

Автоматизированный многослойный конвейер (ETL/ELT) для сбора, валидации, санитарной очистки и хранения данных поисковой аналитики Яндекс Вебмастера в СУБД PostgreSQL.

## 🏗 Архитектура данных

Проект построен по методологии разделения слоев хранения хранилища данных (DWH):
1. **RDL (Raw Data Layer)** — слой сырых данных. Содержит слепки выгрузок в неизменном виде. Реализована *идемпотентность* — при повторной загрузке пересекающиеся даты автоматически перезаписываются, защищая базу от дубликатов.
2. **PPL (Pre-processed Layer)** — слой предобработки. Выполняет функции **Data Quality**:
   * Очищает URL (`page_path`) от мусорных динамических GET-параметров.
   * Восстанавливает бизнес-логику воронки: подтягивает спрос до показов (`demand >= impressions`) и срезает аномальные клики до уровня показов (`clicks <= impressions`).

## 🛠 Технологический стек
* **Python 3.11+**
* **Polars** — сверхбыстрая обработка и трансформация данных в оперативной памяти.
* **SQLAlchemy 2.0 (Core / ORM)** — транзакционное управление базами данных и пакетная вставка (Bulk Insert).
* **SSHTunnel & Paramiko** — безопасное туннелирование закрытого порта удаленного сервера базы данных через SSH.

## 🚀 Быстрый запуск

1. **Клонируйте репозиторий и настройте окружение:**
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd yandex_webmaster_excel_glob
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта на основе `.env.example` и укажите доступы к вашему SSH и PostgreSQL.

3. **Запустите конвейер:**
   Положите Excel-выгрузку Вебмастера в `data/input/` и выполните:
   ```bash
   python main.py
   ```
